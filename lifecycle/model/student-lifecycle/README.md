# Student Lifecycle (post-conversion)

The second half of the SSEI lifecycle system. The first half, lead cohortisation, is in `../lead-cohortisation/`.

**Start with `SSEI_Student_Lifecycle_Plan.md`.** It is the whole plan and the only thing that needs reading end to end.

The five CSVs are the same model in spreadsheet form, for building and for working lists:

| File | What it holds |
|---|---|
| `SSEI_Student_Stages.csv` | The nine stages a student passes through |
| `SSEI_Student_Playbooks.csv` | The twelve plans, SP-01 to SP-12, with owner, timing and channel |
| `SSEI_Money_Moments.csv` | The six points after the first sale where money changes hands |
| `SSEI_Exam_Calendar.csv` | Structure for the exam and result dates. Cadence filled in, exact dates to be loaded |
| `SSEI_Lifecycle_Fields.csv` | Every field the system needs, what we have today and what blocks what |

Not yet in the team dashboard. The dashboard currently covers the lead half only.
